# vuna logo

标记是**双色 V**：左臂与底部顶点为墨色，右臂上段为青绿，两段在右臂中部共边相接（无缝隙、无错位）。
wordmark 沿用同一套笔画：64 网格、笔画宽 9、小写 `vuna`，字母 v 就是标记本身。

- 形状同时是：小写 `v`、一个未闭合的勾、一根被分成两段的连续笔画（自举的两级在同一位置交接）。
- 颜色是加成而非语义载体：单色版就是实心 `V`，含义不丢。
- wordmark 是几何等线体，不是某款字体，因此没有字体授权问题，也不允许替换成字体排版。

## 文件

| 文件 | 用途 |
| --- | --- |
| `vuna-mark.svg` | 母版标记（浅色背景，双色） |
| `vuna-mark-mono.svg` | 单色标记（印刷、单色场景） |
| `vuna-mark-reversed.svg` | 反白标记（深色背景） |
| `vuna-icon.svg` | 应用图标：圆角方块容器 + 反白标记 |
| `vuna-wordmark.svg` / `vuna-wordmark-reversed.svg` | 横向字标（浅色 / 深色） |
| `preview.png` | 尺寸与背景对照图（由 SVG 渲染，仅供查看） |

VS Code 扩展图标是 `vscode/icon.png`（128×128，由 `vuna-icon.svg` 渲染）。

## 使用规则

- 标记最小尺寸 **16px**；16px 及以下用单色或图标版，双色边界在该尺寸不再区分。
- 字标最小高度 **16px**（约 72px 宽）；更小时只用标记或图标。
- 与背景之间至少留出标记高度的 1/4 作为净空，不要加外框、描边、投影或渐变。
- 不要移动两段的边界位置（右臂 45% 处）、不要给接缝加缝隙、不要把青绿换到左臂。
- 不要拉伸、旋转、重排两臂角度；需要变形时重新画，不要变换现有文件。
- 字标不要重新排版：字母比例、字距与笔画宽度都是参数，不能靠视觉微调。

## 字标的构造

`vuna` 与标记共用 64 网格、笔画宽 9。四个字母的墨迹区间（单位：网格）与字距：

| 字母 | 构造 | 墨迹 x | 墨迹 y | 右侧字距 |
| --- | --- | --- | --- | --- |
| `v` | 标记本身：两臂交于顶点，圆角接头 | 8.95 – 55.05 | 8 – 53.5 | 10 |
| `u` | 两竖 + 半圆底（r=11），**外沿**落基线 | −4.5 – 26.5 | 10 – 49.5 | 13 |
| `n` | 竖 + 肩拱（r=11）+ 竖，**外沿**落 x-height | −4.5 – 26.5 | 9.5 – 49 | 13 |
| `a` | 开口圆弧（r=15.5）终止在竖笔内，右侧是直线 | −0.25 – 36.5 | 9.5 – 49.5 | — |

- 字距是**墨迹到墨迹**的距离，不是字身框：`v→u` 10、`u→n` 13、`n→a` 11。
  圆头字母（`a` 左侧）吃 −2 的光学间距，否则会显得比平边更空。
- 圆弧的**外沿**对齐基线 / x-height，中心线要内缩半个笔画宽；反了会让 `u` 掉出基线、
  `n` 高过 x-height。
- `v` 的顶点用圆角接头，墨迹会低于基线约 4.5；这是标记的形状，字标里保留它，
  不要为对齐基线而改 `v`。
